# Материалы для демонстрации

Это локальные материалы готового анализа банковского ТЗ. Для демонстрации, просмотра отчёта и воспроизведения журнала модель не нужна.

| Файл | Содержимое |
|---|---|
| requirements.pdf | Точный входной документ прогона. Его SHA-256 совпадает с паспортом отчёта. |
| source-lines.json | Текст, извлечённый тем же загрузчиком, что и в CLI. У строк есть номер, страница и служебные признаки. |
| progress.log | Строки с отметками времени из сохранённого журнала. Пересчёт времени при ускоренном воспроизведении выполняет интерфейс. |
| ../reports/submission.md | Готовый Markdown. |
| ../reports/submission.json | Готовый JSON с замечаниями, паспортом, замерами, хешем и координатами цитат. |

Значения SourceLine используются для прокрутки и подсветки. Для точности сверены все 195 цитат из отчёта.
